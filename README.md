# WebcamCapture

Программа видеонаблюдения: детекция объектов через нейросеть + детекция движения.

## Что умеет

- Захват с веб-камеры
- Детекция объектов (MobileNet SSD, 20 классов)
- Детекция движения (MOG2)
- Авто-запись при движении + ручная запись
- Скриншоты
- Звуковые оповещения

## Клавиши

| Клавиша | Действие |
|---------|----------|
| `R` | Запись вкл/выкл |
| `M` | Режим: детекция / движение |
| `N` | Звук вкл/выкл |
| `Пробел` | Скриншот |
| `ESC` | Выход |

## Запуск

1. Открыть `WebcamCapture.sln` в VS 2022
2. Настроить пути к OpenCV в свойствах проекта
3. Скачать `mobilenet_iter_73000.caffemodel` ([MobileNet-SSD](https://github.com/chuanqi305/MobileNet-SSD)) и положить в `models/`
4. Собрать x64/Release, запустить `.exe`

## Требования

- Visual Studio 2022
- OpenCV 4.x (модули dnn, videoio)
- Windows + веб-камера
